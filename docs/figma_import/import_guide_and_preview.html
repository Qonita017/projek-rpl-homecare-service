❖ HomeCare Service — Panduan Import Desain ke Figma

Seluruh layar antarmuka dari website asli telah diekspor ke dalam format vektor SVG murni (Standard Scalable Vector Graphics) yang siap diimpor ke Figma secara instan.

🚀 3 Langkah Mudah Mengimpor ke Figma:

  1. Buka aplikasi Figma (desktop app atau di browser figma.com) dan buat draft file baru (New Design File).
  2. Buka folder docs/figma_import/ di File Explorer Windows Anda.
  3. Tarik (Drag-and-Drop) file HomeCare_Service_Master_All_Frames.svg (atau file per modul) langsung ke dalam canvas Figma.
  4. Selesai! Seluruh frame, layer grup, tombol, kotak teks, dan ikon langsung muncul sebagai vector editable layers yang siap diubah warnanya, diedit teksnya, dan dijadikan Figma Components!
